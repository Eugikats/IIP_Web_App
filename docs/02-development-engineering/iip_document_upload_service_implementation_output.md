## Shared rules used by this service output

This output follows the same implementation pattern as the corrected `CommandCenterQueryService` logic:

```text
1. Resolve tenant/workspace from ITenantContextAccessor.
2. Enforce the relevant backend permission before any read/write.
3. Apply tenantId and workspaceId filters in the repository/query boundary.
4. Return the exact reconciled frontend/backend DTO shape where applicable.
5. Write audit events for state-changing operations and sensitive reads.
6. Never fabricate records when no data exists.
7. Never let an AI/system actor be the final actor for a consequential insurance decision.
8. Surface missing providers as ProviderNotConfiguredException or ProviderUnavailableException.
9. Use ISO 8601 round-trip timestamps for frontend wire strings.
10. Keep Domain free of EF Core, Azure SDKs, and ASP.NET Core.
```



## 1. Scope of this pass

This pass implements **document upload registration logic only**:

```text
IDocumentUploadService
```

Implemented capabilities:

```text
- Validate document upload metadata.
- Enforce documents.upload permission.
- Enforce tenant/workspace context.
- Check Azure Blob Storage provider health/configuration before returning upload instructions.
- Create a document record in canonical store.
- Return a backend-controlled upload target or upload session reference.
- Queue downstream extraction work only after document record exists.
- Write audit event for document upload registration.
```

Not implemented in this pass:

```text
- Actual Document Intelligence extraction result processing.
- Human review/correction.
- Completeness checking.
- Controllers, frontend code, or routes.
```

## 6. Validation rules

```text
- FileName is required.
- ContentType is required.
- SizeBytes must be greater than 0.
- SizeBytes must not exceed configured document upload limit.
- ContentType must be in the allowed upload content type list.
- RelatedEntityType and RelatedEntityId must be consistent if supplied.
- Do not accept path traversal in FileName.
```

## 7. Implementation

```csharp
namespace InsuranceIntelligence.Application.Documents;

internal sealed class DocumentUploadService : IDocumentUploadService
{
    private const long DefaultMaxSizeBytes = 25 * 1024 * 1024;

    private readonly ITenantContextAccessor _tenantContextAccessor;
    private readonly IPermissionService _permissionService;
    private readonly IProviderHealthCheck _providerHealth;
    private readonly IDocumentUploadStorageProvider _storageProvider;
    private readonly IDocumentRepository _documentRepository;
    private readonly IQueueProvider _queueProvider;
    private readonly IAuditWriter _auditWriter;

    public DocumentUploadService(
        ITenantContextAccessor tenantContextAccessor,
        IPermissionService permissionService,
        IProviderHealthCheck providerHealth,
        IDocumentUploadStorageProvider storageProvider,
        IDocumentRepository documentRepository,
        IQueueProvider queueProvider,
        IAuditWriter auditWriter)
    {
        _tenantContextAccessor = tenantContextAccessor;
        _permissionService = permissionService;
        _providerHealth = providerHealth;
        _storageProvider = storageProvider;
        _documentRepository = documentRepository;
        _queueProvider = queueProvider;
        _auditWriter = auditWriter;
    }

    public async Task<DocumentUploadRegistrationResult> RegisterUploadAsync(
        DocumentUploadRegistrationRequest request,
        CancellationToken cancellationToken)
    {
        Validate(request);

        var context = _tenantContextAccessor.Current;
        await _permissionService.EnsureAsync(Permissions.DocumentsUpload, cancellationToken);

        var blobHealth = await _providerHealth.CheckAsync("azure_blob_storage", cancellationToken);
        if (blobHealth.Status != ProviderStatus.Connected)
        {
            throw new ProviderNotConfiguredException("Azure Blob Storage is not configured for document uploads.");
        }

        var documentId = Guid.NewGuid().ToString("N");
        var target = await _storageProvider.CreateUploadTargetAsync(
            new DocumentUploadTargetRequest(
                context.TenantId,
                context.WorkspaceId,
                documentId,
                SanitizeFileName(request.FileName),
                request.ContentType,
                request.SizeBytes),
            cancellationToken);

        await _documentRepository.CreateUploadRecordAsync(new DocumentUploadRecord(
            DocumentId: documentId,
            TenantId: context.TenantId,
            WorkspaceId: context.WorkspaceId,
            FileName: SanitizeFileName(request.FileName),
            ContentType: request.ContentType,
            SizeBytes: request.SizeBytes,
            StoragePath: target.StoragePath,
            RelatedEntityType: request.RelatedEntityType,
            RelatedEntityId: request.RelatedEntityId,
            DocumentType: request.DocumentType,
            Status: DocumentUploadStatusValues.UploadPending,
            CreatedByUserId: context.UserId,
            CreatedAt: DateTimeOffset.UtcNow), cancellationToken);

        await _auditWriter.WriteAsync(new AuditEventCreateRequest(
            TenantId: context.TenantId,
            WorkspaceId: context.WorkspaceId,
            EventType: "document.uploaded",
            ActorType: "user",
            ActorUserId: context.UserId,
            Action: "registered_upload",
            EntityType: "document",
            EntityId: documentId,
            Summary: "Document upload registered.",
            Reason: null,
            CorrelationId: context.CorrelationId,
            OccurredAt: DateTimeOffset.UtcNow), cancellationToken);

        return new DocumentUploadRegistrationResult(
            DocumentId: documentId,
            UploadUrl: target.UploadUrl,
            StoragePath: target.StoragePath,
            Status: DocumentUploadStatusValues.UploadPending,
            ExpiresAt: target.ExpiresAt.ToString("O"));
    }

    private static void Validate(DocumentUploadRegistrationRequest request)
    {
        if (string.IsNullOrWhiteSpace(request.FileName)) throw new ValidationException("fileName is required.");
        if (string.IsNullOrWhiteSpace(request.ContentType)) throw new ValidationException("contentType is required.");
        if (request.SizeBytes <= 0 || request.SizeBytes > DefaultMaxSizeBytes) throw new ValidationException("Invalid file size.");
        if (request.FileName.Contains("..") || request.FileName.Contains('/') || request.FileName.Contains('\\')) throw new ValidationException("Invalid file name.");

        var allowed = new[] { "application/pdf", "image/jpeg", "image/png", "image/tiff" };
        if (!allowed.Contains(request.ContentType, StringComparer.OrdinalIgnoreCase))
        {
            throw new ValidationException("Unsupported file type.");
        }
    }

    private static string SanitizeFileName(string fileName) => Path.GetFileName(fileName).Trim();
}
```
