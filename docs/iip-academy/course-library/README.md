## Shared production

- [Narration notebook](02_Shared_Production/Narration/IIP_TTS_Narration_Generator.ipynb): Google Colab / Google Cloud Text-to-Speech workflow. Reads `NARRATION:` blocks and creates slide MP3s, a full-unit MP3, estimated SRT captions, a timings CSV and a download ZIP. Includes voice audition, pronunciation guidance and selected-slide regeneration. Current unit code is `C01_U1-1`; change it when reusing for another unit. Pricing and free-tier statements are copied source claims, not reverified here.
- [Production playbook](02_Shared_Production/Playbook/how-i-create-work.md): artifact design and analysis workflow drawn from IIP pricing work. Covers answer-first presentation, assumptions, audience, format, design consistency and versioning. This is not a complete lesson/video production manual; the notebook contains the audio and slide-assembly guidance.
