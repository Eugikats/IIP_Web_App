## What to check

1. Each course should show four modules with three lessons each.
2. Choose Start course or Continue learning. The first lesson should show an actual video, not a no-recording placeholder.
3. Play, pause, seek and use the English caption control. Caption timing is estimated and needs editorial review.
4. Choose Download audio, Download slides or Download transcript. When preparation finishes, select Save to save that file. This explicit save action also works on mobile browsers.
5. Read the lesson and complete its practical work using fictional information.
6. Take the ten-question unit quiz independently. The pass mark is 70%. The Academy assistant should be unavailable while the assessment is active.
7. Each module has a fifteen-question assessment. Complete the required lessons before taking it.
8. After all requirements are met, complete the final task's ten-box canvas and written proposal. A person must mark it. Submitting work does not automatically earn a certificate.
9. Check your progress after leaving and returning. Records are stored on the server, not just in that browser.
