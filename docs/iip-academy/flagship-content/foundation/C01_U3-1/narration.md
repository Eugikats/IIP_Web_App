### SLIDE 02 - Core concepts and terminology

**On-screen text:** An AI agent combines five components.

**Visual:** Editable teaching text and an insurance example; no invented system screenshot.

NARRATION:
An AI agent combines five components. A goal sets what it is trying to achieve ("get this claim file complete and ready for assessment"). A reasoning model, usually an LLM, interprets the goal and plans steps. Tools let it act: reading emails, querying the policy administration system, checking a payment status, sending a WhatsApp message, creating a task. Memory keeps track of what has happened so far in the task and sometimes across tasks. Guardrails define what the agent may and may not do : permissions, spending or value limits, topics it must refuse, situations where it must hand over to a person.
END NARRATION

### SLIDE 03 - Core concepts and terminology

**On-screen text:** A useful distinction is between a workflow (a fixed sequence of steps in which an AI model performs some of them) and an agent (which decides for itself...

**Visual:** Editable teaching text and an insurance example; no invented system screenshot.

NARRATION:
A useful distinction is between a workflow (a fixed sequence of steps in which an AI model performs some of them) and an agent (which decides for itself which steps to take and in what order). Many practical "agentic" deployments in insurance are closer to workflows with AI steps, which is often the safer design.
END NARRATION

### SLIDE 04 - Core concepts and terminology

**On-screen text:** The Academy uses a five-level autonomy scale: Level 0 : suggests only (human does everything); Level 1 : drafts outputs for human use; Level 2 : prepares and...

**Visual:** Editable teaching text and an insurance example; no invented system screenshot.

NARRATION:
The Academy uses a five-level autonomy scale: Level 0 : suggests only (human does everything); Level 1 : drafts outputs for human use; Level 2 : prepares and proposes actions that a human approves one by one; Level 3 : acts automatically within defined limits and escalates exceptions; Level 4 : acts fully autonomously. Industry tracking in 2026 shows insurers using agents mainly to summarise, route and accelerate work, with few giving agents material authority over pricing, coverage or claims decisions : that is, most real deployments sit at Levels 1 to 3.
END NARRATION

### SLIDE 09 - AI applications and limitations

**On-screen text:** Agents excel at multi-step, repetitive coordination tasks.

**Visual:** Editable teaching text and an insurance example; no invented system screenshot.

NARRATION:
Agents excel at multi-step, repetitive coordination tasks. Limitations include compounding errors, vulnerability to manipulated inputs (Unit 3.3) and difficulty handling genuinely novel situations.
