### SLIDE 02 - Core concepts and terminology

**On-screen text:** Insurance runs on personal data: names, national identification numbers, phone numbers, addresses, vehicle registrations, medical records, bank details, beneficiary information.

**Visual:** Editable teaching text and an insurance example; no invented system screenshot.

NARRATION:
Insurance runs on personal data: names, national identification numbers, phone numbers, addresses, vehicle registrations, medical records, bank details, beneficiary information. Uganda's Data Protection and Privacy Act 2019 (DPPA) applies to the collection, processing, holding or use of personal data within Uganda, and to processing outside Uganda of data relating to Ugandan citizens. Its supporting Regulations were gazetted in March 2021, and the Personal Data Protection Office (PDPO), under NITA-U, has been operational since August 2021. Every data collector, processor and controller must register with the PDPO. The Act sets out principles of data protection, requires consent for collection and processing subject to exceptions, restricts processing of special personal data, sets conditions for processing personal data outside Uganda, and gives data subjects rights including rights in relation to automated decision-taking.
END NARRATION

### SLIDE 04 - Core concepts and terminology

**On-screen text:** For AI use, four questions guide every professional.

**Visual:** Editable teaching text and an insurance example; no invented system screenshot.

NARRATION:
For AI use, four questions guide every professional. Is personal data needed for this task? Most drafting and summarising can be done with names and identifiers removed or replaced. Where does the data go? Many public AI tools process data on servers outside Uganda and may retain or use inputs, which engages the DPPA's conditions for processing outside Uganda. Is the tool approved? The organisation, not the individual, should decide which tools may handle which data, based on contract terms and security. Is the processing consistent with the purpose for which data was collected? Data collected to process a claim should not be repurposed for marketing via AI without a lawful basis.
END NARRATION

### SLIDE 09 - Recommended techniques

**On-screen text:** Strip or replace identifiers before using AI; use templates with placeholders; use only organisation-approved tools for any personal data; keep special personal data (especially medical information) out of...

**Visual:** Editable teaching text and an insurance example; no invented system screenshot.

NARRATION:
Strip or replace identifiers before using AI; use templates with placeholders; use only organisation-approved tools for any personal data; keep special personal data (especially medical information) out of public tools entirely; ask the data protection officer when unsure.
END NARRATION
